Reiche einen Bericht (z. B. OECD, WEF, UNESCO) zur Aufnahme ein – per Drag & Drop, Datei-Auswahl oder Text einfügen. Funktioniert auch am Handy. Daraus entstehen nur Kandidaten; nichts wird automatisch aktiv – ein Mensch prüft alles im Review-Pull-Request.

Beim Absenden öffnet sich ein vorausgefülltes GitHub-Issue, das du nur noch bestätigst. So braucht diese Seite kein Passwort und keinen Token – die Anmeldung übernimmt GitHub.

Wie es weitergeht

  1. Du bestätigst das vorausgefüllte Issue auf GitHub (Label ingest ist gesetzt).
  2. Der Import läuft automatisch, extrahiert wörtlich belegte Befunde und legt Kandidaten an.
  3. Das Ergebnis wird als Kommentar zurück ins Issue geschrieben; geprüft wird im Review-PR.

Bei einem großen PDF passt der Volltext nicht in ein GitHub-Issue (~64 KB) – das Issue öffnet sich dann ohne Text, und du ziehst die PDF auf der GitHub-Seite ins Feld „PDF anhängen" (klappt auch mobil); der Import liest sie dort. Bei langem eingefügtem Text landet dieser in der Zwischenablage – dann auf der GitHub-Seite ins Textfeld einfügen. Eine direkte PDF-URL geht auch.
