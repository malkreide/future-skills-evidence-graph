## Finding: A11Y-010 — Zielgrösse der Navigations-Links (Touch)

| Feld | Wert |
|---|---|
| **Severity** | medium *(WCAG 2.5.8 ist 2.2 AA; eCH-0059 bindet 2.1 AA → keine Eskalation)* |
| **Status** | closed |
| **Lösung** | `future-skills-evidence-graph` |
| **Check-Reference** | `A11Y-010` |
| **WCAG/Heuristik-Ref** | WCAG 2.5.8 Target Size (Minimum) |
| **Audit-Datum** | 2026-07-18 |
| **Auditor** | Claude (ux-audit Skill) |
| **Journey / Ort** | Topbar-Navigation, alle Seiten — Viewport mobile (375×812) |

### Observed Behavior

Die meisten Ziele sind grosszügig (Theme-Toggle 34px, Selects/Suche 42px,
Metric-Kacheln 90px, Skill-Cards ≥ 144px). **Die Topbar-Navigationslinks sind
jedoch nur 20px hoch** (`.nav-link`, z.B. «Bericht einreichen →», «Architektur
ansehen →», «← Zum Dashboard») — unter dem WCAG-Minimum von 24×24 px. Es sind
eigenständige Navigations-Links (nicht in Fliesstext eingebettet), für die die
Inline-Ausnahme nicht gilt.

Messung (`audit/evidence/2026-07-18-browser-walk.json`, 375px-Viewport):

```
.nav-link "Bericht einreichen →"  : 162 × 20  ← Höhe 20 < 24
.nav-link "Architektur ansehen →" : 178 × 20  ← Höhe 20 < 24
#themeToggle                      :  99 × 34   (ok)
select / input[type=search]       : 313 × 42   (ok)
```

### Expected Behavior

Eigenständige Navigations-Ziele ≥ 24×24 px (WCAG-Minimum), idealerweise 44×44 px
für Touch.

### Evidence

- File: `site/assets/styles.css:142-147` — `.nav-link { font-size: 14px; font-weight: 700; text-decoration: none }` — kein vertikales Padding, Höhe = Zeilenhöhe ≈ 20px
- Messung: `audit/evidence/2026-07-18-browser-walk.json` → `index.targets` (`.nav-link` 162×20 / 178×20)

### Risk Description

Auf dem Handy (Hauptzielgerät laut Einreichungs-Flow «Funktioniert auch am
Handy») treffen Nutzer mit motorischer Einschränkung oder grossen Daumen die
20px-hohen Nav-Links unzuverlässig; benachbarte Links liegen in der Topbar nah
beieinander → Fehlklick-Risiko.

### Remediation

Vertikales Padding statt grösserer Schrift — Optik bleibt, Ziel wächst:

```diff
  .nav-link {
    color: var(--blue);
    font-size: 14px;
    font-weight: 700;
    text-decoration: none;
+   display: inline-flex;
+   align-items: center;
+   min-height: 44px;      /* oder padding-block: 12px */
  }
```

### Effort Estimate

**S** — reiner CSS-Padding-Fix.

### Dependencies / Blockers

Keine.
